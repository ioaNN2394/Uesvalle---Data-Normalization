FLUJO COMPLETO - PASO A PASO:
=============================

1. Usuario en Frontend
   └─► Click "Subir archivos"

2. Selecciona archivo.xlsx
   └─► Validación local (size, ext)
   └─► Se agrega a cola visible

3. Click "Procesar" o "Iniciar"
   ├─► uploadFile() (para cada archivo)
   │   └─► POST /api/etl/upload/ con FormData
   │
   └─► createETLJob()
       └─► POST /api/etl/jobs/ con file_ids[]

4. Backend recibe POST /api/etl/upload/
   ├─► Validar archivo nuevamente
   ├─► Guardar en etl_uploads/
   ├─► Crear ETLFile DB
   └─► Responder con {uploaded: [...], failed: 0}

5. Frontend recibe upload response
   └─► Extrae IDs y crea job

6. Backend recibe POST /api/etl/jobs/
   ├─► Validar file_ids
   ├─► Crear ETLRun
   ├─► Asociar files al run
   ├─► Encolar en Celery
   └─► Responder 202 Accepted

7. Celery worker procesa el job
   ├─► ETLOrchestrator.execute()
   │   ├─► Extract: pandas.read_excel()
   │   ├─► Transform: limpiar datos
   │   └─► Load: persistir (cuando completo)
   │
   └─► Actualizar ETLRun.status = 'completed'
       Actualizar ETLFile.status = 'success'
       Logs guardados

8. Frontend puede obtener status
   └─► GET /api/etl/status/
       ├─► total_jobs, running_jobs, success_rate
       └─► Mostrar en dashboard/widget
