ENDPOINTS DISPONIBLES:
======================

POST   /api/etl/upload/
       Descripción: Subir archivo(s) Excel
       Headers: Content-Type: multipart/form-data (automático)
       Body: FormData con campo 'file'
       Respuesta: { uploaded: [{id, filename, ...}], failed: 0 }
       Status: 200 OK (éxito) o 400 Bad Request (error)

POST   /api/etl/jobs/
       Descripción: Crear job ETL
       Headers: Content-Type: application/json
       Body: { file_ids: [...], dry_run: false, cancel_on_error: true }
       Respuesta: { id, status: "queued", meta: {...} }
       Status: 202 Accepted

GET    /api/etl/jobs/
       Descripción: Listar todos los jobs
       Query params: ?status=running&ordering=-started_at
       Respuesta: [{id, status, started_at, ...}]
       Status: 200 OK

GET    /api/etl/jobs/:id/
       Descripción: Obtener detalles del job
       Respuesta: {id, status, started_at, finished_at, meta}
       Status: 200 OK

POST   /api/etl/jobs/:id/cancel/
       Descripción: Cancelar job en progreso
       Respuesta: {id, status: "cancelled"}
       Status: 200 OK

GET    /api/etl/status/
       Descripción: Estado general del sistema ETL
       Respuesta: {total_jobs, running_jobs, success_rate, ...}
       Status: 200 OK
